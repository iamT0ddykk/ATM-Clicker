# 💰 ATM Clicker

> Um jogo estilo clicker sobre um caixa eletrônico: clique para ganhar mais dinheiro! 💵

## 📖 Sobre o projeto

O **ATM Clicker** é um jogo simples no estilo **clicker**, onde o jogador deve clicar no caixa eletrônico para acumular dinheiro.

O projeto foi desenvolvido com **React + Vite** com o objetivo de praticar e entender melhor os **Hooks do React**, principalmente `useState`, `useEffect` e `useRef`.

## 🎯 Objetivo do projeto

O principal objetivo foi praticar conceitos fundamentais do React, utilizando Hooks para controlar o estado, efeitos e referências dos elementos da interface.

## 🚀 Como executar

Clone o repositório:

```bash
git clone https://github.com/iamT0ddykk/ATM-Clicker.git
```

Entre na pasta:

```bash
cd ATM-Clicker
```

Instale as dependências:

```bash
npm install
```

Execute o projeto:

```bash
npm run dev
```

Depois, acesse o endereço mostrado pelo Vite no terminal.
